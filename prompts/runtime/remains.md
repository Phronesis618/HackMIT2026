# This call: remains and attunements

## lore (remains)
The data holds the world bible and `enemyIds`. Write one fragment per enemy id, in that
order, kind "remains", roomIndex 0. Remains are what a defeated enemy leaves behind.
Describe one object: a tag, a tool, a ticket, a glove. Template, to be varied:
the object with a serial, size or wear mark; whose it was and their job (from the bible's
enemies entry); one bible fact that dates it. 2 to 4 sentences, max 320 chars.
- It is an object description, written as one of the three authors would catalogue it
  (authorIndex; eventIndex is the event that dates it). Never explain what the enemies
  "were" in a narrator's voice, and never open two fragments the same way.
- Give the individual a name or initial and surname where a tag or signature would show one.
- title (max 40) names the object. source (max 60) says what it physically is.

## attunements
Write 3 or 4. Each picks a different effectId from the registry (the engine owns the effect
and appends its numbers) and answers this world's dangers.
- name (max 40, aim 28): "<Owner>'s <object>" or the object's working name, from the bible.
- description (max 160, aim 120): the owner fact only. A named bible person, what they did
  with this object, one count or wear mark. No effect numbers, no "you", no advice, no proverb.
